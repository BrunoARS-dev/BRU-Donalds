# BRU-Donalds

**Status: em desenvolvimento**

Projeto de estudo de um sistema de autoatendimento para restaurantes, desenvolvido com Next.js e Prisma.

O repositório ainda está em fase inicial. As funcionalidades de autoatendimento estão sendo construídas, e a aplicação ainda não está pronta para uso.

## Objetivo

Praticar o desenvolvimento de uma aplicação para que clientes possam consultar um cardápio e realizar pedidos de forma autônoma.

## Tecnologias

- Next.js
- React
- TypeScript
- Prisma

## Executar localmente

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
